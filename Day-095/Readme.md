# Day 95 - Phase 3 (Heap Greedy + Greedy Reconstruction)

## Problems Solved
1. IPO (Greedy + Heap)
2. Queue Reconstruction by Height (Greedy Sorting)

---

## Key Concepts

### 1. Heap Greedy
- Dynamically select best affordable option
- Use heap for efficient max retrieval

### 2. Greedy Reconstruction
- Sort strategically before placement
- Insert elements directly into valid positions

---

## Key Learnings

- Heap-based greedy works well with dynamic constraints
- Correct ordering simplifies reconstruction problems
- Sorting strategy is often the key insight in greedy problems

---

## Pattern Recognition

- Resource optimization → heap greedy
- Ordering constraints → greedy reconstruction

---

## Complexity

### Problem 1
- Time: O(n log n)
- Space: O(n)

### Problem 2
- Time: O(n²)
- Space: O(n)

## Focus Areas

- Heap optimization
