# Day 79 - Phase 3 (Lazy Segment Tree + Bitmask DP)

## Problems Solved
1. Range Module (Segment Tree / Interval Handling)
2. Minimum Cost to Connect Two Groups (Bitmask DP)

---

## Key Concepts

### 1. Lazy Propagation
- Delay updates for efficiency
- Handle range modifications

### 2. Bitmask DP
- Encode connection states
- Ensure full coverage of nodes

---

## Key Learnings

- Segment trees handle complex range operations
- Lazy propagation improves performance
- Bitmask DP is powerful for matching problems

---

## Pattern Recognition

- Range updates → segment tree
- Matching problems → bitmask DP

---

## Complexity

### Problem 1
- Time: O(n) per operation (simplified)
- Space: O(n)

### Problem 2
- Time: O(m * 2^n * n)
- Space: O(2^n)
