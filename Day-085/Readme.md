# Day 85 - Phase 3 (Game Theory DP + Partition DP)

## Problems Solved
1. Stone Game III (Game Theory DP)
2. Partition Array for Maximum Sum (Partition DP)

---

## Key Concepts

### 1. Game Theory DP
- Maximize score difference
- Opponent plays optimally

### 2. Partition DP
- Try all partition sizes
- Track max segment value

---

## Key Learnings

- Game problems often reduce to difference DP
- Partition DP is useful for segmentation problems
- Tracking local max improves efficiency

---

## Pattern Recognition

- Game theory → minimax DP
- Partition → segmentation DP
