# Day 83 - Phase 3 (Subsequence DP + Greedy Heap)

## Problems Solved
1. Number of Longest Increasing Subsequence (DP + Counting)
2. Minimum Number of Refueling Stops (Greedy + Heap)

---

## Key Concepts

### 1. Subsequence DP
- Track both length and count
- Merge results carefully

### 2. Greedy + Heap
- Delay decisions until necessary
- Use heap for optimal choices

---

## Key Learnings

- LIS problems can involve counting, not just length
- Greedy can require revisiting previous decisions
- Heap enables efficient optimal selection

---

## Pattern Recognition

- LIS → DP with counting
- Greedy → heap-based decisions

---

## Complexity

### Problem 1
- Time: O(n^2)
- Space: O(n)

### Problem 2
- Time: O(n log n)
- Space: O(n)
