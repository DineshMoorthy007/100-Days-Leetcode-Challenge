# Day 86 - Phase 3 (Combinatorics DP + String Transformation)

## Problems Solved
1. Number of Ways to Form Target String (Combinatorics DP)
2. Minimum Insertions to Make Palindrome (String DP)

---

## Key Concepts

### 1. Combinatorics DP
- Count ways using frequency arrays
- Multiply choices across positions

### 2. String Transformation DP
- Reduce to LCS problem
- Use reverse string

---

## Key Learnings

- Counting problems often involve combinatorics + DP
- Precomputation simplifies DP transitions
- Many string problems reduce to LCS

---

## Pattern Recognition

- Counting → combinatorics DP
- String transform → LCS
