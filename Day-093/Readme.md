## Key Concepts

### 1. Tree DP
- Track rob/skip states
- Use recursive postorder traversal

### 2. Greedy Heap
- Assign ladders to largest climbs
- Use heap for optimal resource management

---

## Key Learnings

- Tree DP often involves multiple states per node
- Greedy decisions can be optimized using heaps
- Resource allocation problems appear frequently in interviews

## Pattern Recognition

- Tree recursion → DP states
- Resource optimization → greedy heap
