# Day 97 - Phase 3 (Union Find + Greedy Stack)

## Problems Solved
1. Number of Good Paths (Union Find)
2. Remove K Digits (Greedy Stack)

---

## Key Concepts

### 1. Union Find
- Merge valid graph components
- Count equal-valued connected groups

### 2. Greedy Stack
- Remove larger previous digits greedily
- Maintain increasing stack order

---

## Key Learnings

- Offline processing simplifies graph connectivity problems
- Monotonic stacks help construct optimal sequences
- Greedy removals often lead to globally optimal answers

---

## Pattern Recognition

- Connectivity grouping → Union Find
- Sequence minimization → monotonic stack

---

### Problem 1
- Time: O(n log n)

- Time: O(n)
