\# Day 98 - Phase 3 (Sorting + LIS Optimization)



\## Problems Solved

1\. Russian Doll Envelopes (Sorting + LIS)

2\. Maximum Width Ramp (Monotonic Stack)



\---



\## Key Concepts



\### 1. 2D to 1D Optimization

\- Sort one dimension strategically

\- Apply LIS on the second dimension



\### 2. Monotonic Stack

\- Store best prefix candidates

\- Use reverse traversal to maximize span



\---



\## Key Learnings



\- Sorting can simplify multi-dimensional problems

\- LIS is often hidden inside interval-style problems

\- Monotonic stacks help preserve useful candidates efficiently



\---



\## Pattern Recognition



\- Nested envelope constraints → sorting + LIS

\- Width optimization → monotonic stack



\---
