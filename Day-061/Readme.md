# Day 61 - Phase 3 (Advanced Interview Prep)

## Problems Solved
1. Regular Expression Matching (Hard - Dynamic Programming)
2. Shortest Path in Binary Matrix (Medium-Hard - BFS)

---

## Key Concepts

### 1. Dynamic Programming (Advanced)
- 2D DP table for pattern matching
- Handling special characters (`.` and `*`)
- Multiple state transitions

### 2. Graph (BFS)
- Shortest path in grid
- 8-direction traversal
- Level-order BFS guarantees minimum steps

---

## Key Learnings

- Complex DP problems require careful handling of edge cases and transitions
- `*` in regex introduces multiple possibilities (0 or more occurrences)
- BFS is the go-to approach for shortest path in unweighted graphs
- Always validate start/end conditions early in grid problems

---

## Pattern Recognition

- Pattern matching with conditions → DP
- Grid shortest path → BFS
- Multiple conditions → state-based DP

---

## Complexity

### Regular Expression Matching
- Time: O(m × n)
- Space: O(m × n)

### Shortest Path in Binary Matrix
- Time: O(n²)
- Space: O(n²)
