# Day 78 - Phase 3 (Segment Tree + Graph DP)

## Problems Solved
1. Range Sum Query - Mutable (Fenwick Tree)
2. Minimum Cost to Reach Destination in Time (Graph + DP)

---

## Key Concepts

### 1. Fenwick Tree
- Efficient updates and queries
- Prefix-based structure

### 2. Graph + DP State
- Add time as dimension
- Optimize cost under constraint

---

## Key Learnings

- Fenwick tree is simpler alternative to segment tree
- Graph problems often need multi-dimensional states
- Priority queue helps manage optimal transitions

---

## Pattern Recognition

- Range queries → Fenwick / Segment Tree
- Graph + constraint → DP state expansion

---

## Complexity

### Problem 1
- Time: O(log n) per operation
- Space: O(n)

### Problem 2
- Time: O(E * T log(E*T))
- Space: O(E * T)
