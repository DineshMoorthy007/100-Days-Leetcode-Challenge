# Day 46 - Stack + Parentheses

## Problems Solved
1. Minimum Remove to Make Valid Parentheses (Medium)
2. Remove Invalid Parentheses (Hard)

## Key Concepts
- Stack for tracking indices
- BFS for minimum removals
- Validity checking using balance

## Key Learnings
- Mark invalid positions instead of modifying string repeatedly
- BFS ensures optimal solution
- Use visited set to avoid duplicates

## Pattern Recognition
- Parentheses validation → stack
- Minimum removals → BFS
- Multiple answers → BFS / Backtracking

## Complexity
- Time: O(n) / Exponential (Hard problem)
- Space: O(n)
