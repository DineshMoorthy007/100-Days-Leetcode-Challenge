# Day 51 - Advanced Patterns

## Problems Solved
1. Longest Consecutive Sequence (HashSet)
2. Sliding Window Maximum (Deque)

## Key Concepts
- HashSet optimization
- Deque (Monotonic Queue)
- Sliding window maximum

## Key Learnings
- Avoid sorting by using hash structures
- Use deque for efficient window operations
- Maintain useful elements only

## Pattern Recognition
- Sequence problems → HashSet
- Sliding window max → Deque

## Complexity
- Time: O(n)
- Space: O(n)
