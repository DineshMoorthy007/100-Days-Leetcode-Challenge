## Key Learnings

- Matrix problems can often be reduced to 1D histogram problems
- BFS is effective for shortest path in state space problems
- Avoid revisiting states using a visited set

## Pattern Recognition

- Matrix → Histogram → Stack
- State transitions → BFS
- Shortest path → BFS
