# Day 77 - Phase 3 (Advanced Counting + Tree DP)

## Problems Solved
1. Count of Range Sum (Prefix + Merge Sort)
2. Longest Path With Different Adjacent Characters (Tree DP)

---

## Key Concepts

### 1. Prefix Sum Counting
- Transform into prefix differences
- Use merge sort to count valid pairs

### 2. Tree DP
- Track top 2 child paths
- Combine only when valid

---

## Key Learnings

- Merge sort can solve counting efficiently
- Tree DP often requires combining multiple child states
- Constraints change how paths are formed

---

## Pattern Recognition

- Prefix + range → counting problems
- Tree DP → longest path variants

---

## Complexity

### Problem 1
- Time: O(n log n)
- Space: O(n)

### Problem 2
- Time: O(n)
- Space: O(n)
