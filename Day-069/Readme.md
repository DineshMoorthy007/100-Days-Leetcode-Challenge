# Day 69 - Phase 3 (Bitmask DP + Meet in the Middle)

## Problems Solved
1. Smallest Sufficient Team (Bitmask DP)
2. Closest Subsequence Sum (Meet in the Middle)

---

## Key Concepts

### 1. Bitmask DP
- Represent features using bits
- Optimize subset selection

### 2. Meet in the Middle
- Split into halves
- Combine using binary search

---

## Key Learnings

- Bitmask DP is powerful for subset problems
- Meet in the middle reduces exponential complexity
- Choosing correct paradigm drastically improves performance

---

## Pattern Recognition

- Bitmask → subset optimization
- Meet in the middle → large subset constraints

---

## Complexity

### Problem 1
- Time: O(2^n * people)
- Space: O(2^n)

### Problem 2
- Time: O(2^(n/2) log(2^(n/2)))
- Space: O(2^(n/2))
